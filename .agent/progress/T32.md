## Design notes
- Layout frame must match across editor and snapshot so stored positions stay meaningful: file elements only are laid
  out (additions excluded), deterministically (seeded Math.random for fcose; fixed bounding box for breadthfirst), and
  appliances are part of the layout whenever the file has <= 400 of them (hidden by a class when "Show appliances" is
  off, incl. the snapshot) so the frame does not depend on that toggle.
- Added nodes: stored position, else computed near positioned neighbours / free spot (recomputed each structural change).
- Fresh layout is translated so the laid-out nodes' min x/y = 0 (breadthfirst had a viewport-dependent offset).
- Modal Esc now capture-phase + preventDefault, so Esc in a dialog over the expanded diagram doesn't also collapse it.
