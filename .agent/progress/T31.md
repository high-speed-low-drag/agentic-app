## Design notes
- Editing an added element in the table updates the addition's own `attrs` (no overrides; no revert/"was" cue).
  Overrides on added ids are still accepted by the backend (additions applied before overrides).
- Delete: only added elements; deleting an added node deletes connected additions after a confirmation listing them.
  Removal also drops overrides on removed ids and strips them from profile target id lists (`removeAdditions`).
- `Revert all` clears overrides and additions (always confirms when there are additions); switching network clears both.
- New `NetworkTopology.max_id` (all PGM components, e.g. ieee14 voltage_regulator ids up to 601) for id allocation.
- Diagram re-lays out only on structural changes (`structureKey`), not value edits of added elements.
- If an addition has an error, validation skips override + study checks (avoid follow-on noise).
- Shunt `g1` optional (fixed 0); node `u_rated` has no backend default (UI prefills most common u_rated).
- Deferred: transformers (2/3-winding), sources, asym components, deleting file elements, editing added node u_rated/name
  in the table (delete + re-add instead).
