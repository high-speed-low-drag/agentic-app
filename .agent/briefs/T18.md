## Why
In the current `voltageDivergingColor(u, theme, span = 0.08)` (`frontend/src/components/network/graph.ts`), anything
above 1.00 pu turns reddish. The user wants a neutral, no-alarm band, defined by four values they can set:
`[fullUnder, bandLow, bandHigh, fullOver]`, defaulting to `[0.90, 0.95, 1.05, 1.10]`.

## Build
1. **Scale model:** a pure module, e.g. `frontend/src/lib/voltageScale.ts`, with:
   - a `VoltageScale` tuple type and `DEFAULT_VOLTAGE_SCALE`;
   - `validateScale(s)`: strictly ascending, finite, each value within 0.5–1.5 pu, returning an error message or null;
   - `voltageColor(u, scale, theme)`:
     - when `bandLow ≤ u ≤ bandHigh`, return exactly the neutral token (`voltMid`);
     - between `fullUnder` and `bandLow`, mix from a visible starting tint to full `voltUnder` (blue). Start at about
       25–30 % tint just outside the band, not 0 %, so crossing a limit is visible;
     - between `bandHigh` and `fullOver`, mix the same way towards `voltOver` (red);
     - beyond the outer values, return full colour;
     - for null or NaN, return the axis colour, as today.
   Replace `voltageDivergingColor` uses with it, or keep it as a thin wrapper.
2. **Neutral colour:** check the `--c-volt-mid` tokens. In light mode it should be near-white (e.g. `#f4f3ef`); in dark
   mode the dark surface tone. Make sure a neutral node still shows against the diagram background, using the T17 node ring.
3. **Persistence:** a `useVoltageScale()` hook backed by `localStorage` (key `gridsim.voltageScale.v1`). Wrap reads and
   writes in try/catch, validate on load, and fall back to the defaults on anything invalid. It applies to every run in
   this browser.
4. **UI, in the results Network snapshot legend** (`NetworkSnapshotView.tsx` and the legend component):
   - **Legend:** the voltage legend shows a blue ramp, a flat neutral section labelled "within band", and a red ramp,
     with ticks at the four values. Section widths may be equal; they don't need to be proportional.
   - **"Edit scale" button:** a small pencil or sliders icon next to the legend that opens a popover. Use the existing
     Modal or popover pattern from the UI kit, or a small anchored panel.
   - **Popover contents:**
     - four labelled `NumberInput`s (pu, step 0.01): "Full blue below", "Band from", "Band to", "Full red above";
     - an inline validation error when the values aren't ascending; invalid values are not applied;
     - "Match run limits", which sets `bandLow`/`bandHigh` from the run's frozen case limits (`u_min_pu`/`u_max_pu`)
       and keeps the current outer gaps;
     - "Reset to defaults".
   - **Live updates:** changes apply immediately, including during playback.
5. Check whether any other view colours by voltage, e.g. an element table or heatmap, and if so use the same scale there.
   The voltage envelope chart keeps its limit lines as they are.
