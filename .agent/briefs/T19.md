## Problem
`frontend/src/results/TimeseriesChart.tsx` draws limit `markLine`s, but `valueAxis()` in
`components/charts/theme.ts` uses `scale: true`, so the y-axis auto-fits to the data. ECharts doesn't extend the axis
for markLines, so limits outside the data range aren't drawn. Voltage lines such as 0.90 / 1.10 disappear when the
voltages stay between about 0.97 and 1.04. Loading at 100% usually shows only because the data reaches near it.

## Change
1. **Pure helper**, e.g. `axisRangeWithLimits(dataMin, dataMax, limits, padFrac = 0.05)`. It returns `{min, max}`
   covering both the data and all limit values, with a small padding of about 5% of the span. Handle empty or all-null
   data: use the limits alone, or fall back to auto.
2. **`TimeseriesChart`:** compute the data min/max over all series (ignoring nulls) and set the y-axis `min`/`max` from
   the helper whenever there are limits. Without limits, keep the current auto-fit. The dataZoom slider stays as it is
   (x-axis). Check whether a y-axis zoom exists; if it does, keep it working.
3. **Labels:** show the value in the limit labels, e.g. "u_min 0.90", "u_max 1.10", "limit 100%". Use pu with 2–3
   decimals, and % for loading.
4. **Other charts:** apply the same fix to every chart that draws limit lines:
   - the Violations tab focus modal (`results/views/ViolationsView.tsx` `FocusModal`);
   - `ElementTimeseriesView` (check whether it passes limits; if it plots voltage or loading without limit lines, add
     them from the run limits, using the same `useRunContext().limits`);
   - `VoltageEnvelopeView`: check how it draws its limit lines and make sure they always show.
   Limits come from the run's frozen case (`useRunContext().limits`), not the T18 display scale.
