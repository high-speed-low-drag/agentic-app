## Problem
`frontend/src/components/network/NetworkDiagram.tsx` already styles `edge[in_service = 0]` as dashed with opacity 0.5.
On the results snapshot (`results/views/NetworkSnapshotView.tsx`), three things override it: the overlay's
`branchColor` (loading colour; at 0% that's a grey-tan like every other line), `branchWidth`, and the wide amber
`edge.changed` halo, which appears because the out-of-service status came from an edit. The user switched off IEEE 14
branch node 1 – node 2, and it looked like every other line. The user wants to still see it, but with a clear
"disconnected" cue.

## Change (shared diagram component, so both the case editor and the results snapshot get it)
1. **Out-of-service branches** get a dedicated style that has the highest priority over the overlay colour/width and
   the changed halo. Put it last in the stylesheet, and/or make the overlay skip these elements:
   - a thin line (about 1.5 px), in a neutral grey token, with long dashes (e.g. `line-dash-pattern` [6, 5]);
   - no loading colour and no width scaling;
   - a small "off" marker at the edge midpoint (e.g. a `⊘` or "off" label on the edge with a small background, or a
     midpoint node);
   - the tooltip and title "Out of service".
   If the branch is also changed (edited), show the amber cue as a thin outline or underlay that doesn't hide the dashes,
   not the wide halo. Applies to 3-winding hub edges too.
2. **Out-of-service appliances** (sym_load/sym_gen glyphs): a hollow grey glyph and a dashed connector stub.
3. **Islanded nodes:** nodes with no in-service path to any source, after the case's overrides and file statuses, are
   drawn hollow and grey, with the tooltip "Not energised". Add a pure helper, e.g. `energisedNodes(topology)` in
   `components/network/`, that does a BFS from source nodes over in-service branches. Use the effective topology
   (`effectiveTopology`) in the case editor and `runTopology` in the results. Treat a branch as in service only if both
   statuses are 1 (or the in_service flag is true).
4. **Results snapshot:** for out-of-service branches, the details panel shows "Out of service — no flow" in place of
   the loading value. Islanded nodes show "Not energised" in place of a voltage colour; the snapshot values may be
   null or NaN for them, so check.
5. **Legend** (`Legend.tsx`): add "Out of service" and "Not energised" entries, shown only when such elements exist,
   or always if that's simpler.
6. Use theme tokens that work in both light and dark mode.
