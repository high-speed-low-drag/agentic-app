## Build
1. **Symbol module** `components/network/symbols.ts`: pure functions that return SVG data URIs, given theme colours.
   Draw with strokes on a transparent background, readable at 18–28 px.
   - **2-winding transformer:** two overlapping circles side by side. Stroke each circle in its side's voltage-level
     colour (from_node and to_node `u_rated`, using the same colour mapping as the nodes). Add a light fill in the
     surface colour so the line beneath doesn't show through.
   - **3-winding transformer:** three overlapping circles in a triangle, coloured by node_1/2/3.
   - **Generator** (sym_gen, and asym_gen if present): a circle with a "~" sine stroke inside.
   - **External grid** (source): a square with diagonal hatching.
   - **Shunt:** a capacitor (two parallel plates) if b1 > 0, or a reactor (an inductor coil) if b1 < 0. b1 is
     susceptance; add it to the topology payload for shunts if it's missing, which may need a small backend addition.
     If it's genuinely unavailable, use a generic shunt symbol.
   - **Out-of-service variant:** a hollow, muted-grey stroke.
2. **Transformer symbols on 2-winding transformers:** add one overlay node per transformer, class `xfmr-symbol`,
   data `{kind: 'branch', eid}`, that is **not part of the layout**. After layout, and whenever either end node moves
   (drag, re-layout, fit), place it at the midpoint of its edge and rotate it to the edge angle if feasible; otherwise
   keep it axis-aligned. Make it ungrabbable but selectable: clicking it selects the transformer branch, exactly like
   clicking the edge. Keep the edge itself, including its loading colour and width on the snapshot. Move the T12 "off"
   label so it doesn't collide with the symbol, e.g. offset it along the edge.
3. **3-winding:** style the existing hub node with the 3-circle symbol.
4. **Generators, source, shunts:** replace their glyph styles with the symbol images, roughly 16–20 px for appliances and
   22–26 px for the source. Keep the stub connectors.
5. **Cues on symbols:**
   - selection: an accent ring or overlay;
   - changed: an amber ring or underlay;
   - out of service: the hollow grey variant (for transformers, when the branch is out of service);
   - not energised: applies to nodes only.
6. **Theme:** regenerate the symbol images when the chart theme changes (light/dark) and update the styles in place,
   without a re-layout.
7. **Zoom:** keep symbols legible. Use `min-zoomed-font-size` or zoom-dependent sizing so they don't vanish or get huge.
8. **Legend:** show small symbol icons (the same SVGs as `<img>`) for Transformer, Generator, External grid and Shunt,
   alongside the existing Line/Link entries and the status entries.
