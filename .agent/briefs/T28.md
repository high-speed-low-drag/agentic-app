## Build
1. **Expand button:** a Maximize icon next to + / − / fit, with the aria-label "Expand diagram". In both the case
   editor and the results snapshot.
2. **Expanded view:**
   - a fixed overlay covering the whole browser window, above the app shell, with the theme background;
   - the diagram fills it, with the details panel on the right at its normal width, and the legend at the bottom
     (or legend and clock, on the snapshot);
   - on the snapshot, the playback bar (play, slider, step label, speed buttons) sits at the top of the overlay,
     together with the voltage-scale editor and the clock;
   - a header bar with a title (the case or run name plus "Network"), a Collapse button (Minimize icon,
     aria-label "Collapse diagram") and a "Full screen" toggle (described below).
   Render it through a portal, or lift the layout so the *same* Cytoscape instance moves into the overlay. Prefer
   keeping one instance so the selection, zoom, pan and positions are preserved. If re-mounting is unavoidable, carry
   over the selection and node positions explicitly. Call `cy.resize()` and fit after the transition.
3. **Wheel zoom:** `userZoomingEnabled` is true only while expanded, and is restored to false on collapse.
   Collapsed behaviour stays exactly as it is now: the wheel scrolls the page.
4. **Leaving:**
   - Esc collapses: the first Esc leaves true full screen if active, then a further Esc collapses the overlay.
   - Clicking Collapse collapses.
   - Focus returns to the Expand button.
   - Lock body scroll while expanded.
5. **Edit in table while expanded:** collapse first, then do the normal reveal-in-table jump.
6. **True full screen:** a "Full screen" toggle button in the overlay header calls `requestFullscreen()` on the
   overlay element (and `exitFullscreen` to leave). Keep its state in sync through the `fullscreenchange` event. Hide
   the button if `document.fullscreenEnabled` is false. Leaving true full screen keeps the overlay open.
7. Use theme tokens in light and dark mode. Keep the minimum widths sensible.
