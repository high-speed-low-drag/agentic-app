## Why
The current snapshot scale is a user-defined four-point scale `[fullUnder, bandLow, bandHigh, fullOver]` stored per
browser (`gridsim.voltageScale.v1`), with a grey neutral band and an "Edit scale" popover. The user wants a simpler,
more informative scale defined by only three values that come from the run settings: the frozen case's
`limits.u_min_pu` (blue), 1.0 pu (green) and `limits.u_max_pu` (red), with two in-between colours:
**blue – teal – green – yellow – red**. No override on the Run result view; just use the run's limits.
